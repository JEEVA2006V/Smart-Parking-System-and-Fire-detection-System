# Smart Parking System

## Overview

The Smart Parking System is an IoT-based project designed to monitor parking slot availability while also providing safety features such as gas leakage detection and fire detection. The system enables real-time monitoring through the Blynk platform, improving parking management and safety.

## Objective

To develop an intelligent parking system that detects vehicle occupancy, monitors environmental conditions, and provides instant alerts for gas leakage and fire hazards.

## Components Used

* ESP32 / ESP8266
* Ultrasonic Sensor
* Gas Sensor (MQ Series)
* Flame Sensor
* Blynk Platform
* Jumper Wires
* Breadboard
* Power Supply

## Working Principle

The ultrasonic sensor detects the presence of vehicles in parking slots and updates the occupancy status. The gas sensor continuously monitors the environment for harmful gas leakage, while the flame sensor detects the presence of fire. The ESP32/ESP8266 processes the sensor data and sends real-time updates to the Blynk dashboard for remote monitoring.
